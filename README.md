# ARFaceFilters2022 — AR Eyewear Virtual Try-On

## Project Overview
ARFaceFilters2022 is a Unity-based augmented reality prototype that uses MediaPipe Face Landmarker to detect facial landmarks and position eyewear filters over the user's face.

The project explores how AR virtual try-on can improve the online eyewear shopping experience.

## Objectives
- Detect facial landmarks in real time.
- Position eyewear filters around the eyes.
- Allow users to select different eyewear styles.
- Explore AR applications in e-commerce.

## Technologies Used
- Unity 2022.3
- C#
- MediaPipe Unity Plugin
- Face Landmarker
- Unity UI

## Features
- Webcam-based face tracking
- Eyewear overlay
- Multiple filter options
- Unity-based user interface

## Project Structure
- `Assets/` — Scenes, scripts, UI, and filter assets
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration

## How to Run
1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk**.
4. Choose the downloaded `ARFaceFilters2022` folder.
5. Open it with a compatible Unity 2022.3 version.
6. Open the `ARFaceFilterScene` scene.
7. Press Play and grant camera access.

Additional MediaPipe setup may be required on a new computer.

## Current Limitations
This is an AR virtual try-on prototype, not a complete VR shopping environment. Android camera support may require further debugging.
